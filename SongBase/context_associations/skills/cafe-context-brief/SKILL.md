# 咖啡店每日情景建议

执行 [标准流程](../../BRIEF-WORKFLOW.md)，以 [报告模板](../../brief_template.md) 为输出骨架。门店标签与边界见 [关联库说明](../../README.md)，归档入口见 [报告索引](../../briefs/README.md)。

用户给日期即可开始；缺少非关键偏好时使用流程默认值并说明。相对日期以 Asia/Shanghai 的用户日期解释；出现明确日期冲突时先核实，其他资料核对可继续。

每次完成给用户看的 Markdown 报告和可追溯的 evidence.json，并更新归档索引。对话中同时返回当日情景、候选特征、前端配置及文件链接，不能只贴归档路径。

保留人工 ZMPD 与当前模型预测的区别，缺失就写缺失。未确认关联可以作为待讨论提案，不自动转为已批准。每种命中情景没有必选配额。

这是按请求执行的策展流程，不是定时任务。用户可自行配置前端；也可明确要求脚本生成，在其确认段落与情景配置后执行标准流程的“脚本草稿分支”，读取 FlowSystem 对应操作流程，保存要求、草稿、完整曲目及情景实际位置。普通情景建议不默认运行排程；试生成不确认或清空CD、不写回歌曲关联。
