# Flowset 个人审美打标·第六波

本批共 100 首，用于扩充 ZMPD 人工真值。请按自己的第一感受独立标注，不参考模型预测。

## 如何开始

1. 双击 `开始第六波打标.html`。
2. 点击“选择音乐文件夹”。
3. 选择同目录下的 `音乐第六波测试`。
4. 页面显示 `100 / 100 首已完整标注` 后，点击“导出标注 JSON”。

第六波使用独立的浏览器草稿空间，不会与前五批混在一起。五个维度保持不变：

- 适合的时段：8–11 / 11–14 / 14–17 / 17–20，可多选
- 能量状态：平静 / 渐进 / 有冲劲 / 爆发 / 不确定
- 噪音程度：1–10
- 摇摆速率：1–10
- 负担程度：1–10

## 选曲与数据边界

- 仅使用 SongBase 中有正式主风格标签、且能唯一对应到本地音频的歌曲。
- 已排除前五批出现过的文件名，并用 SHA-256 排除相同音频内容。
- 用固定随机种子抽样，优先补齐现有正式风格样本较少的类别；第六批新增分布为 Ambient 6、Post-Rock 9、Electronic 28、Jazz 2、Folk 22、Rock 23、Hip-Hop 10。
- 新增后七类正式风格样本数为 35–36 首；100 首有 79 个显示艺人项。抽样优先限制同一艺人 2 首，为满足风格配额，按 SongBase 艺人分组回填后最多 4 首。
- `音乐第六波测试` 中的音频是指向 `SongBase/SongResources` 同一文件内容的硬链接，不额外复制约 787 MB 音频。
- 完整 QQ MID、文件大小、SHA-256 和来源路径见 `第六波测试清单.csv`。

导出的 JSON 是第六批原始标注证据。完成前不要覆盖或改名音频文件；导出后把 JSON 留在本目录即可。
