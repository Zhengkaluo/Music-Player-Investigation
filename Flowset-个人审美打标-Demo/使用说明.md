# Flowset 个人审美打标 Demo

## 如何开始

1. 解压收到的 ZIP，不要直接在压缩包预览中打开页面。
2. 双击 `开始打标.html`。推荐使用最新版 Chrome、Edge 或 Safari。
3. 点击“选择音乐文件夹”，选择 ZIP 里的 `音乐` 文件夹。
4. 自由试听每首歌，并按自己的感受选择标签。
5. 需要时可修改默认审美维度，或新建自己的维度和选项。
6. 点击页面底部“导出标注 JSON”，把生成的 `.json` 文件发回给研究者。

## 替换成自己的音乐

可以删除 `音乐` 文件夹里的样例音频，换成任意 MP3、M4A、WAV、FLAC、OGG 或 AAC 文件。重新打开页面并选择这个文件夹即可，不需要修改网页代码。

## 隐私与数据

- 音频只在浏览器本地播放，不会上传网络。
- JSON 不包含音频，只保存文件名、文件大小、标签、备注和必要的版本信息。
- 页面会把未导出的草稿保存在当前浏览器的本地存储中；在公共电脑上完成后可点击“清空草稿”。
- 如果移动到另一台电脑继续标注，请先导出 JSON；在新电脑上点击“导入 JSON”，再选择相同音乐文件夹。

## 浏览器限制

本地网页不能在没有授权的情况下自动扫描旁边的文件，因此每次重新打开页面后都需要点击一次“选择音乐文件夹”。这是浏览器的隐私保护机制，不是程序故障。
