# Flowset 个人审美打标·第八波

本批共 100 首：96 首新增补标歌曲和 4 首盲测锚点。锚点用于检查跨批次标尺漂移；打标时不需要识别它们，请始终按这一次听到的第一感受独立作答。

## 如何开始

1. 双击 `开始第八波打标.html`。
2. 点击“选择音乐文件夹”。
3. 选择同目录下的 `音乐第八波测试`。
4. 页面显示 `100 / 100 首已完整标注` 后，点击“导出标注 JSON”。

第八波有独立的浏览器草稿空间，不会和前七批混在一起。五个维度保持不变：

- 适合的时段：8–11 / 11–14 / 14–17 / 17–20，可多选
- 能量状态：平静 / 渐进 / 有冲劲 / 爆发 / 不确定
- 噪音程度：1–10
- 摇摆速率：1–10
- 负担程度：1–10

## 样本边界

- 96 首新增曲目按正式主风格配额选取：Ambient 14、Post-Rock 14、Electronic 12、Jazz 14、Folk 14、Rock 14、Hip-Hop/R&B 14。
- 其中 2 首已有直接 Flow 衔接证据、只缺 ZMPD；另外 94 首同时缺 Flow 衔接和 ZMPD，之后仍需另做歌曲对测试。
- 59 首已在当前 480 首 catalog；其余 37 首仅补齐人工 ZMPD，不会因此直接扩充 catalog。
- 4 首锚点分散在列表中，来自此前不同批次和不同尺度区间。页面不会提示其身份。
- 所有歌曲均有正式主风格标签、唯一音频身份和可播放的本地音频。
- 音频使用指向既有资源的硬链接，不额外复制内容。
- 完整身份、文件大小、SHA-256、缺口状态和来源路径见 `第八波测试清单.csv`。
- 锚点旧标注保存在 `第八波锚点审计.json`，请在完成本轮打标前不要查看。

导出的 JSON 是第八波原始标注证据。完成前不要覆盖或改名音频文件；后续合并会把 96 首新增样本和 4 首重复测量分开处理。
