# Flowset 个人审美打标·第七波

本批共 100 首，用于补齐人工 ZMPD，并通过少量重复样本检查跨批次标尺漂移。打标时不需要识别重复样本，请始终按这一次听到的第一感受独立作答。

## 如何开始

1. 双击 `开始第七波打标.html`。
2. 点击“选择音乐文件夹”。
3. 选择同目录下的 `音乐第七波测试`。
4. 页面显示 `100 / 100 首已完整标注` 后，点击“导出标注 JSON”。

第七波使用独立浏览器草稿空间，不会和前六批混在一起。五个维度保持不变：

- 适合的时段：8–11 / 11–14 / 14–17 / 17–20，可多选
- 能量状态：平静 / 渐进 / 有冲劲 / 爆发 / 不确定
- 噪音程度：1–10
- 摇摆速率：1–10
- 负担程度：1–10

## 样本边界

- 95 首是已有直接 Flow 衔接证据、只缺人工 ZMPD 的歌曲。
- 5 首是分散在列表中的盲测重复样本，用于完成后检查批次偏移；页面不会提示其身份。
- 所有歌曲均有正式主风格标签、唯一音频身份和可播放的本地音频。
- 音频文件使用指向 `SongBase/SongResources` 的硬链接，不额外复制音频内容。
- 完整身份、文件大小、SHA-256 和来源路径见 `第七波测试清单.csv`。
- 锚点旧标注保存在 `第七波锚点审计.json`，请在完成本轮打标前不要查看。

导出的 JSON 是第七波原始标注证据。完成前不要覆盖或改名音频文件；导出后把 JSON 留在本目录即可。后续合并时，95 首新增样本和 5 首重复测量会分别处理，不会直接用新结果覆盖旧锚点。
