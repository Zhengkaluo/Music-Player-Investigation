# Flowset 个人审美打标·第五波

这一波用于补齐“风格衔接测试”中最有分析价值、但尚缺 Flowset 的曲目。

## 如何开始

1. 双击 `开始第五波打标.html`。
2. 点击“选择音乐文件夹”。
3. 选择同目录下的 `音乐第五波测试`。
4. 完成 24 首后导出 JSON。

第五波使用独立的浏览器草稿空间，不会与前四波的本地草稿混在一起。默认维度与前四波保持一致：

- 适合的时段：8–11 / 11–14 / 14–17 / 17–20，可多选
- 能量状态：平静 / 渐进 / 有冲劲 / 爆发 / 不确定
- 噪音程度：1–10
- 摇摆速率：1–10
- 负担程度：1–10

## 选曲口径

- 共 24 首，按“能新增多少条前后双端 Flowset 完整的衔接”和“在已完成衔接测试中的出现次数”排序。
- 音频全部来自 `SongBase/SongResources`，并已核对实际文件存在。
- `本当みたい` 经音频 SHA-256 复核后确认已在第一波完成标注，已从本波排除。
- `reflection eternal` 虽然曾存在于第二波的音频文件夹，但没有出现在当次导出的标注 JSON 中，因此仍纳入第五波。

完整曲目、QQ MID、出现次数和优先级见 `第五波测试清单.csv`。
